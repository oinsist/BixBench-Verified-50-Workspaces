# 50 个独立分析工作区

用户确认使用独立文件夹，一个 GitHub 仓库承载 50 题，原始数据通过 Releases 分发。每题保留原文，提供 TASK.md、AGENTS.md、data、analysis、outputs。只从 CapsuleData 打包输入，排除答案字段、参考 Notebook、历史结果和凭据。33 份共享数据包按题解压为独立文件。

准备脚本使用 Python 标准库，支持单题、全部题目、指定新目录，下载校验 SHA-256，安全解压，不覆盖现有数据。环境依赖和额外 R/命令行工具说明随仓库分发。先验证本地 50 题，再验证从 GitHub 全新克隆后的准备流程。
